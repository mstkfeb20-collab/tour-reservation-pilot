# ツアー予約 パイロット（tazuna）

tazuna をテンプレートにして始めた、パイロット用の案件リポジトリです。ID 設計書から転記した要件をもとに、1機能（J110 振込データ取込）を GitHub Copilot に実装させ、ハーネスが役に立つかを確かめます。

## 確かめること

1. ID 設計書（`docs/design/`）から転記した要件（`docs/requirements/S-22-001_振込データ取込.md`）と作業一覧（`docs/tasks/S-22-001_振込データ取込.md`）だけで、エージェントが正しく実装できるか
2. hooks（保護ファイル・禁止コマンド）と Lint が、実際の Copilot で効くか
3. 振り分け先に違和感のある行があったか。あれば rule-log に記録し、行末の `{…}` で直すか、tazuna に戻す提案をする
