# 版B（c0be985）設計書レビュー結果

## 指摘・質問

| 種別 | 根拠の行ID | 指摘 |
| --- | --- | --- |
| 重複 | S-17-001/D-04002/1,S-22-002/D-04002/1 | 「金額の1円未満は切り捨てる」という共通ルールを予約取消の設計書でも重複して定義している |
| 食い違い | S-21-001/D-02003/1,S-22-002/D-01006/2 | 未振込予約では返金額の行を表示しない一方、処理設計では取消料と返金額を画面に出力するとしている |
| 質問 | S-22-002/D-01005/3,S-22-002/D-04001/2 | 返金額が0円になった場合でも REFUND に返金待ちを登録するのか |

| テスト仕様の抜け | S-22-002/D-06001/1,S-22-002/D-06007/1 | 一連の更新のトランザクション境界と更新順序を確認するテストがない |
| テスト仕様の抜け | S-22-002/D-04009/1,S-22-002/D-04012/1 | 期限後入金の扱いと返金番号の採番を確認するテストがない |

### まとめ

画面表示と処理設計の返金額の扱いに食い違いがあります。取消処理の競合時と返金額0円時の扱いは、設計書だけでは確定できないため質問としました。取消結果の記録、トランザクション、更新順序、期限後入金、返金番号についてテスト仕様が不足しています。
