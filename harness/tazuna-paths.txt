# 1行1パターン（* は / を含む任意の文字列）。ここにあるファイルは案件で直接直さず、tazuna で直す。
#
# 一覧にないファイル（AGENTS.md、CODEOWNERS、deny-commands.txt、protected-paths.txt、
# docs/、proj-* スキル、lint/domain など）は案件のもの。取り込み時に上書きされない。
#
# docs/design/ID設計.xlsx（と書き出しの ID設計.md）は、型（書類の種類・記載項目・設計項目）と
# 案件が書いたもの（機能一覧・書類一覧・状態・記載）が1つのファイルにあるので、取り込みで上書きしない。
# 型が変わったときは、取り込みスクリプトが新しい Excel と型の差分を .tazuna-download/ に取り出す。案件の Excel に手で反映する。
