# ツアー予約（見本）

> 以下は見本です。題材は himotoki の評価用設計書（ツアー予約システム）と同じ業務です。案件では自分の要件に置き換えてください。

## REQ-001 予約の入力条件

- 背景: 予約時に人数・残席・期限を確かめないと、受けられない予約が登録される。
- 完了条件:
  - 条件を満たす予約は登録でき、合計金額 = 大人料金 × 大人人数 + 子供料金 × 子供人数 になり、ツアーの残席数が人数分減る。
  - 人数（大人＋子供）が0人なら登録できない。
  - 子供のみ（大人0人）では登録できない。
  - 人数が残席数を超えると登録できない。残席ちょうどは登録できる。
  - 予約は出発日の7日前まで。6日前以降は登録できない。
  - 備考は80文字まで。81文字以上は登録できない。

## REQ-002 予約の取消

- 背景: 取消できる期間と、取消後の状態を決めておかないと、残席数が実態とずれる。
- 完了条件:
  - 出発日の前日までは取り消せ、取消すると残席数が人数分戻る。
  - 出発日の当日以降は取り消せず、残席数も変わらない。
  - 取り消し済みの予約は再度取り消せない（残席数が二重に戻らない）。
  - 振込状況は 未振込(0) → 振込済(1) → 取消(9)、または 未振込(0) → 取消(9) の順にしか進まない。取消から他の状態には戻らない。

## REQ-003 取消料と返金額

- 背景: 取消料率と端数処理を決めておかないと、返金額が担当者によって変わる。
- 完了条件:
  - 取消料率は、出発日の21日前まで0%、20日前〜8日前20%、7日前〜2日前30%、前日40%。
  - 未振込の予約を取り消すときは、取消料を請求しない（取消料0円、返金0円）。
  - 取消料 = 合計金額 × 取消料率。1円未満は切り捨てる。
  - 返金額 = 振込額 − 取消料。0円を下回らない。

## テスト仕様

- REQ-001: 人数0人・子供のみ・残席ちょうどと残席＋1人・出発日の7日前と6日前・備考80文字と81文字を確かめる。
- REQ-002: 出発日の前日と当日、取り消し済みの予約の再取消、取消後の残席数を確かめる。
- REQ-003: 取消料率の境界（21日前・20日前・8日前・7日前・2日前・前日）、未振込、1円未満の切り捨て、返金額が0円を下回らないことを確かめる。
