## S-23-001 ジョブ設計書：J110振込取込

### 型・API・DB 制約で書けなくする

- [ ] S3 の消込は500明細ごとにコミットする（S-23-001/D-08004/1・処理単位・コミット間隔）
- [ ] J110 の終了コードは 0 正常、4 不一致・返金対象・要確認あり、8 異常（S-23-001/D-08013/1・終了コードの体系）

### Lint を足す

- [ ] J110 は振込入金通知ファイルの到着で起動する（S-23-001/D-08002/1・起動条件）
- [ ] 6:00 までにファイルが届かなければ起動せず、運用担当に知らせる（S-23-001/D-08002/2・起動条件）
- [ ] J120 残席突合は、J110 が終了コード 0 または 4 で終わった後に動く（S-23-001/D-08003/1・先行・後続関係）

### テストを書く（業務承認の要らない振る舞い）

- [ ] J110 が動いている間は、ロックファイル /var/run/tour/J110.lock で同じジョブの起動を止める（S-23-001/D-08009/1・多重起動の防止）

### 動かして測り、PR に結果を添える

- [ ] J110 は平常10分以内、繁忙期でも30分以内に終える（S-23-001/D-08007/1・処理時間・バッチウィンドウ）
- [ ] 夜間ジョブネット全体は、7:00 の窓口開店までに終える（S-23-001/D-08007/2・処理時間・バッチウィンドウ）
- [ ] 3千件のファイルを30分以内に処理できることを、本番相当の環境で測る（S-23-001/D-08007/3・処理時間・バッチウィンドウ）
- [ ] J110 は 1GB 以内のメモリで動く（S-23-001/D-12006/1・メモリの見積もり）

### 承認されているか確かめる

- [ ] J110 が異常終了したら、運用担当は原因を確かめ、入力ファイルはそのままで再実行する（S-23-001/D-08012/1・オペレーター対応手順）
- [ ] 形式エラーのときは銀行に再送を頼み、届いたファイルで再実行する（S-23-001/D-08012/2・オペレーター対応手順）
- [ ] 不一致・返金対象・要確認が1件でもあれば、予約担当にメールで件数を知らせる（S-23-001/D-09006/1・障害通知）
- [ ] J110 が異常終了したら、運用担当にすぐ知らせる（S-23-001/D-09006/2・障害通知）
- [ ] J110 の開始・終了と終了コードを監視し、6:30 を過ぎても終わらなければ知らせる（S-23-001/D-16001/1・運用監視項目）

## S-24-001 IF定義書：IF-11振込入金通知ファイル

### 型・API・DB 制約で書けなくする

- [ ] ヘッダー（1件）・データ（0件以上）・トレーラー（1件）・エンド（1件）の順に並ぶ（S-24-001/D-07002/1・電文・ファイルレイアウト）
- [ ] ヘッダーのデータ区分は '1'（S-24-001/D-07002/2・電文・ファイルレイアウト）
- [ ] ヘッダーの作成日は 6桁 YYMMDD（S-24-001/D-07002/3・電文・ファイルレイアウト）
- [ ] ヘッダーの口座番号は 7桁。当社の入金口座 1234567 であること（S-24-001/D-07002/4・電文・ファイルレイアウト）
- [ ] データ区分 1桁、'2'（S-24-001/D-07002/5・電文・ファイルレイアウト）
- [ ] 照会番号 6桁、数字。銀行が明細ごとに振る番号で、同じ勘定日の中で一意（S-24-001/D-07002/6・電文・ファイルレイアウト）
- [ ] 勘定日 6桁 YYMMDD、起算日 6桁 YYMMDD（S-24-001/D-07002/7・電文・ファイルレイアウト）
- [ ] 金額 10桁、数字、右詰めで前ゼロ、円単位（S-24-001/D-07002/8・電文・ファイルレイアウト）
- [ ] うち他店券金額 10桁（S-24-001/D-07002/9・電文・ファイルレイアウト）
- [ ] 振込依頼人コード 10桁（S-24-001/D-07002/10・電文・ファイルレイアウト）
- [ ] 振込依頼人名 48桁、半角カナと英数字、左詰めで後ろ空白（S-24-001/D-07002/11・電文・ファイルレイアウト）
- [ ] 仕向銀行名 15桁、仕向店名 15桁（S-24-001/D-07002/12・電文・ファイルレイアウト）
- [ ] 取消区分 1桁。'0' 通常、'1' 取消（組戻し）（S-24-001/D-07002/13・電文・ファイルレイアウト）
- [ ] EDI情報 20桁（S-24-001/D-07002/14・電文・ファイルレイアウト）

- [ ] エンドはデータ区分 '9'、残りは空白（S-24-001/D-07002/17・電文・ファイルレイアウト）
- [ ] 各レコードの項目は、上に書いた順に隙間なく並ぶ（項目の間に埋め草や区切りはない）（S-24-001/D-07002/18・電文・ファイルレイアウト）
- [ ] YYMMDD の日付（作成日・勘定日・起算日）は、西暦 2000 + YY 年として読む（S-24-001/D-07002/19・電文・ファイルレイアウト）
- [ ] 文字コードは半角英数字とカナだけの Shift_JIS（S-24-001/D-07003/1・文字コード・改行・区切り）
- [ ] 1レコード200バイトの固定長、レコードの区切りは CRLF（S-24-001/D-07003/2・文字コード・改行・区切り）
- [ ] 照会番号 → TRANSFER_IMPORT.INQUIRY_NO（S-24-001/D-07008/1・項目の対応表）
