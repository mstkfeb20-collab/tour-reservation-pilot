## Lint を足す

- [ ] 入力チェックのエラーごとにメッセージIDを1つ決め、同じエラーには同じIDを使う（S-13-001-001・エラーとメッセージの対応）
- [ ] すべてのログに 相関ID・利用者ID・機能ID を出す（S-13-001-032・ログの出力項目）
- [ ] J110 のログには ステップ名・照会番号・判定結果 を出す（S-13-001-033・ログの出力項目）
- [ ] 氏名・電話番号・メールアドレスはログに伏せ字で出す（S-13-001-034・個人情報のマスキング）
- [ ] 操作ログとアプリログには代表者の氏名・電話番号・メールアドレスを出さず、会員番号だけを出す（S-13-001-035・個人情報のマスキング）
- [ ] 通知メールには件数だけを書き、振込依頼人名や金額は書かない（S-13-001-036・個人情報のマスキング）
- [ ] ERROR で出すメッセージIDは、すべて監視定義に登録する（S-13-001-038・監視キーワードとの対応）
- [ ] E-TR-001 と E-TR-002 は監視定義に登録する（S-13-001-039・監視キーワードとの対応）
- [ ] System.out / System.err に出さず、必ずロガーを使う（S-13-001-040・標準出力の禁止）
